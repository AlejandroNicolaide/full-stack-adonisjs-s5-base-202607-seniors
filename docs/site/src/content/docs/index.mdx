**FlowSync** es una aplicación web de gestión de tareas personales que mantiene
sincronizadas las tareas del usuario con su Google Calendar (ver `docs/PRD.md`
en el repo para el detalle completo del producto).

Este sitio documenta el estado actual del proyecto: un starter kit full-stack
con autenticación por access tokens (AdonisJS 7 + React 19), sobre el que se
construye el resto del MVP.
